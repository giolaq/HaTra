# Habit Tracker 2026

A simple and effective web app to track your daily habits throughout 2026.

## Features

- Track multiple habits with checkboxes for each day of the week
- Visual progress indicators showing completion percentages
- Statistics showing done/not done counts per day
- Progress chart visualization
- Data persists in browser local storage

## Usage

Simply open `index.html` in your web browser, or run:

```bash
npm start
```

Then navigate to `http://localhost:8080`

## Habits Included

- Wake up at 05:00 ⏰
- Gym 💪
- Reading / Learning 📖
- Day Planning 📝
- Budget Tracking 💰
- Project Work 🎯
- No Alcohol 🍷
- Social Media Detox 🌿
- Goal Journaling 📔
- Cold Shower 🚿
